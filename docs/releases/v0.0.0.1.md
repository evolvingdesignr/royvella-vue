# v0.0.0.1 — Hello, World.

Release date: November 15, 2026.

The first official release of the Vue/Nuxt portfolio, published to the existing Vue review site at https://royvella-vue.netlify.app from `main` in `evolvingdesignr/royvella-vue`.

## Included

- 67 Art & Design entries with 134 optimized WebP images and thumbnails, meaningful alt text, and approved titles.
- One continuous grid ordered by character studies and drawings, illustrations, apparel/products, branding/marketing, then graffiti/lettering.
- Three consecutive PCS Panthers entries; category-order lightbox navigation, arrow keys, Escape/backdrop closing, and focus restoration.
- Individually extracted PDF designs replacing duplicate presentation boards; overlapping compositions remain intact. No individual authorship claims were added. Requested contribution captions were removed from all 14 affected entries.
- Permanent exclusion records and build checks prevent the five unwanted artworks from returning.
- Existing ten Motion / 3D entries and Work project pages preserved.
- Footer and changelog use the official release name. Prior changelog entries remain historical records of the reference site.

## Deployment boundary

Only the existing Vue Netlify site is released. No production-domain, DNS, custom-domain, or Next.js Netlify project changes are included. Desktop source artwork remains untouched. This display version is intentionally not an npm semantic version.

## Validation

- `npm run test:gallery`: all four tests passed.
- `npm run validate:gallery`: all five excluded artworks absent.
- `npm run typecheck` and `npm run build`: passed.
- Built production server: all 14 page routes returned 200 with the official release name; unknown project returned 404.
- All 134 artwork URLs returned 200 and decoded; 67 unique full-image hashes. Retired board URLs returned 404.
- Approved title mappings, PCS positions 30–32, final graffiti sequence, Motion / 3D records, and untouched Desktop PDF checksum verified.
- Server-rendered order matches catalog order; existing lightbox navigation uses that same collection.
- Interactive desktop/mobile browser regression remains unverified: browser access host unavailable. HTTP and source checks do not establish interactive behavior.
